### 1.2 Actual Origin of the HTTP 400 Error
The error was **not generated by Meta Model API, SAM 3.1, or Muse Spark 1.3**.
It originated entirely within the local application use case at:
[`src/application/create-citizen-report-draft.ts`](file:///C:/Users/leolm/Desktop/Proyectos_AI/MyVirtualCommunity-AI-Hackathon-Edition/src/application/create-citizen-report-draft.ts#L380):

    throw new InvalidImageEvidenceError('Image base64 data is missing or empty.');

### 1.4 Diagnostic Evidence Summary
- **Unity Wire Payload:** When no image was attached in Unity C#, `draftReq.image = null`, but Unity's `JsonUtility.ToJson` instantiated a default instance `{"fileName":"","mimeType":"","base64":""}`.
- **Backend Misinterpretation:** The backend treated the presence of the `image` object as an assertion that an image had been attached, and then failed because `base64` was an empty string.
- **Unnecessary Coupling:** Because this check executed before Step 5, Muse Spark text interpretation was completely blocked when no image was selected.
- **Provider Isolation:** Zero calls reached SAM 3.1 or Meta; the request was aborted before any external provider dispatch.

## 2. Minimal Corrective Implementation

### 2.1 Backend Contract Hardening: `CreateCitizenReportDraftUseCase`
In [`src/application/create-citizen-report-draft.ts`](file:///C:/Users/leolm/Desktop/Proyectos_AI/MyVirtualCommunity-AI-Hackathon-Edition/src/application/create-citizen-report-draft.ts#L370-L425):
1. **Attached Image Detection:**
   An image is now recognized as attached if and only if `base64` is provided as a non-empty string (`base64.trim().length > 0`), or a valid `imageBuffer` is supplied.
2. **Graceful Optional Evidence Flow (Case A):**
   If `input.image` is omitted, `null`, `{}` or contains an empty base64 string (`""`), `hasAttachedImage` is evaluated as `false`.
   - `evidence` is set to `null`.
   - `visualAnalysis` is set to `null`.
   - Zero image decoding or sanitization executes.
   - Zero calls are dispatched to SAM 3.1.
   - Execution proceeds directly to Muse Spark 1.3 for text interpretation.
3. **Malformed Nonempty Payloads (Case D):**
   If `base64` is provided as a non-empty string, but contains invalid base64 characters or cannot be decoded as a valid PNG/JPEG by Sharp, it explicitly throws `InvalidImageEvidenceError` (HTTP 400), preventing silent reinterpretation.

### 2.2 Unity Client DTO Normalization: `ApiClient.cs`
In [`unity-client/Assets/Scripts/ApiClient.cs`](file:///C:/Users/leolm/Desktop/Proyectos_AI/MyVirtualCommunity-AI-Hackathon-Edition/unity-client/Assets/Scripts/ApiClient.cs#L234-L242):
Added pre-transmission normalization in `SendPostRequest`:
```csharp
string jsonBody = JsonUtility.ToJson(requestPayload);
if (requestPayload is CitizenReportDraftRequestDto draftReq && draftReq.image == null)
{
    // JsonUtility instantiates default instances for null nested Serializable classes.
    // Normalize empty dummy image block to explicit null on the wire.
    jsonBody = jsonBody.Replace("\"image\":{\"fileName\":\"\",\"mimeType\":\"\",\"base64\":\"\"}", "\"image\":null");
    jsonBody = jsonBody.Replace("\"image\":{\"base64\":\"\",\"fileName\":\"\",\"mimeType\":\"\"}", "\"image\":null");
}
```

### 2.3 Interpretation Messaging Alignment
Updated [`buildDeterministicInterpretation`](file:///C:/Users/leolm/Desktop/Proyectos_AI/MyVirtualCommunity-AI-Hackathon-Edition/src/application/create-citizen-report-draft.ts#L619-L630) and [`MockMetaModelAdapter`](file:///C:/Users/leolm/Desktop/Proyectos_AI/MyVirtualCommunity-AI-Hackathon-Edition/src/adapters/mock-meta-model-adapter.ts#L393-L398) so that when `visualAnalysis` is `null`, `additionalDetails` accurately states:
*"Reporte registrado sin evidencia fotográfica"* / *"Report registered without photographic evidence"*, eliminating any spurious claims of attached photos.
