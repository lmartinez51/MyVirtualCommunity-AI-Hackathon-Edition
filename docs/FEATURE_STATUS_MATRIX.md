## 2. Summary of Key Architectural & Product Limitations (`CONFIRMED`)

1. **Monolithic Player/UI Script:** `FirstPersonPlayer.cs` (8,692 lines) mixes locomotion, interaction routing, dialogue, citizen reporting, aerial debug cameras, keypad modals, artifact dossiers, and IMGUI rendering in a single file.
2. **Developer Debug Modes Exposed in Normal Play:** Aerial Free-Flight Drone (`[V]`) and Satellite View (`[G]`) with ground teleport (`[T]`) are currently unbound from any debug gate, allowing players to bypass exploration boundaries.
3. **External Runtime Dependency for Players:** Running the full world currently requires launching the Node.js TypeScript backend via `scripts/launch-demo.ps1` alongside `MyVirtualCommunity.exe`.
4. **IP & Commercial Clearance Backlog:** `IP-01` (12 third-party horror-franchise artifacts in `BackroomsLevel1Scene.unity` / `BackroomsLevel1Builder.cs` / `DiscoveryJournalCatalog.cs`) is **`REPLACED — creator visual review complete; not formal legal clearance`** (with backward-compatible legacy save ID migration), and `IP-02` (former `"SS GEORGIE"` sewer prop and `"Georgie"` intake naming in `BorderCorridorScene.unity` / `UndergroundSewerBuilder.cs`) is **`REPLACED — creator visual review complete; not formal legal clearance`** with an original decorative folded collector maintenance notice. Remaining `HIGH` items — Backrooms/Kane Pixels naming (`IP-03`), unlicensed real-world storefront signage (`IP-04`), consumer/newspaper Reality-Bridge trademarks (`IP-05`), `media/arch-ads/camila_loop.mp4` (`IP-06`), and external live-stream links (`IP-07`) — remain open before any commercial build or Fellowship trailer release (see [IP & Asset Provenance](IP_AND_ASSET_PROVENANCE.md)).
5. **Legacy Build Scene & Workspace Clutter:** `HandshakeScene.unity` remains enabled in `EditorBuildSettings.asset`, and development assets (`Assets/TutorialInfo/`, `Assets/Development/BobbleheadProofOfConcept/`, `Assets/Staging/ElenaPilot/`, ~40 one-off Editor verification suites) remain in the repository pending future code-phase cleanup.
